🛡️ Outlier Treatment Best Practices (Non-Destructive)
1. Winsorization (Capping)

Caps values exceeding 1st / 99th percentiles to boundary values, preserving sample count while eliminating gradient shock.

2. Robust Scaling

Uses median and IQR instead of mean and standard deviation, preventing outliers from compressing valid feature ranges.

3. Power Transformations

Log1p or Yeo-Johnson transforms heavily skewed tails into standard normal bell curves for linear model convergence.
